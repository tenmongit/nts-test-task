# Тестовое задание — NTS Design

Данный репозиторий — тестовое задание на позицию системного администратора, задание было выполнено на личном ноутбуке.

## Стенд

Ноутбук с Ubuntu Desktop 24.04, на котором поднят гипервизор KVM/libvirt, сеть libvirt `default` (мост `virbr0`, NAT, 192.168.122.0/24).

| ВМ | Роль | ОС | IP | Примечание |
|---|---|---|---|---|
| nts-srv1 | сервер: статика, VLAN, сервер WireGuard | Ubuntu Server 24.04 | 192.168.122.3 | vlan10 — 10.10.10.1/24, vlan20 — 10.20.20.1/24, wg0 — 10.0.8.1 |
| nts-srv2 | второй узел: VLAN, клиент WireGuard | Ubuntu Server 24.04 | 192.168.122.4 | vlan10 — 10.10.10.2/24, vlan20 — 10.20.20.2/24, wg0 — 10.0.8.2 |
| pve | гипервизор Proxmox VE 9.2.2 | Debian (Proxmox VE) | 192.168.122.20 | CPU host-passthrough, вложенная виртуализация |
| alpine-test (VM 100) | ВМ внутри Proxmox | Alpine Linux 3.24 | — | 768 МБ, 1 ядро, диск 4 ГБ, мост vmbr0 |

## Видеодемонстрация

> ЗАПОЛНИТЬ: ссылка на видео и одна строка о том, что в нём показано.

## Как проверить

```bash
# Задание 1: статический адрес и два VLAN-интерфейса
ip -br a
ip -d link show vlan10        # vlan protocol 802.1Q id 10

# Задание 2: вход по паролю отклоняется, туннель поднят
ssh -o PubkeyAuthentication=no ntstest@192.168.122.3   # Permission denied (publickey)
sudo wg show                  # latest handshake и счётчики transfer

# Задание 3: веб-интерфейс Proxmox и вложенная виртуализация
# https://192.168.122.20:8006
egrep -c '(vmx|svm)' /proc/cpuinfo   # больше нуля
```

## Ограничения стенда

Всё на одном ноутбуке, Proxmox работает во вложенной виртуализации, репозиторий без подписки (no-subscription), ВМ с минимальными ресурсами, VLAN проверялись между двумя ВМ, а не на физическом коммутаторе.

## Безопасность

Приватные ключи в репозиторий не попадают, в примерах конфигов заглушки, staged-изменения проверяются gitleaks перед каждым коммитом.
